## 通用平面机构工作流

机构任务除静态装配验收外，还必须验证多个输入角度下的运动状态。不要只验证初始姿态。

1. 先根据尺寸定义运动学参数：旋转中心、曲柄半径、连杆两孔中心距、滑动轴和旋转轴。
   所有 SolidWorks API 长度参数使用米，角度使用度。
2. 分开建立固定件、主动件、连杆和滑块。零件原点应具有明确语义：
   - 曲柄件原点位于旋转中心；
   - 连杆原点位于两孔中心的中点，局部 +Y 轴沿两孔中心连线；
   - 滑块原点位于与连杆连接的销轴中心。
3. 插入后读取 observation 中的真实组件实例名，再建立配合或运动操作；禁止猜测实例后缀。
4. 平面曲柄滑块可用 `assembly_set_crank_slider_pose` 设置并检查一个确定姿态。
   必填组件名、`crankRadius`、`rodLength` 和 `angleDeg`；通常滑动轴为 +Y、旋转轴为 +Z。
   `synchronizedComponents` 可声明与主动曲柄同步旋转的飞轮、齿轮或轴：
   `ratio=1` 表示同速，`ratio=2, reverse=true` 表示反向半速。
5. 至少检查一个完整周期中的上止点、下止点和两个中间位置。机器验收应验证：
   滑块行程等于两倍曲柄半径、连杆长度保持不变、周期首尾姿态一致、同步传动比正确。
6. 机构运动前解除移动组件的固定状态；固定机架不能参与姿态更新。运动后重建并保存装配体。

### 多关节平面链

串联灯臂、机械臂或折叠支架使用 `assembly_set_planar_chain_pose`。每个 segment
给出米制 `length`、相对上一段的 `angleDeg`，以及一个 `componentName` 或多根
平行杆的 `componentNames/axisOffsets`。组件局部 +X 必须沿杆长方向；求解器会
把每根杆放在两关节点的中点并返回所有 `anchors`。转轴装饰件放入
`jointComponents`，灯头/夹爪等末端件放入 `endComponents`。

至少采样收拢、中间、升高三种姿态，并验证：每段关节点距离保持等于杆长、关节
角不越限、同段平行杆共享角度、末端姿态满足任务要求。禁止把多段相对角误当成
绝对角，也不能为每个姿态手写不相干的组件坐标。

### 径向重复展开机构

伞骨、径向支架和可展开天线使用 `assembly_set_radial_deployable_pose`。
先定义中心、展开轴、参考径向、轮毂/滑套半径、主肋长度、撑杆连接距离和撑杆
长度，再在 `bays` 中列出每个方位的主肋与撑杆实例。所有杆件局部 +X 必须沿
两销孔中心线；方位角应均匀覆盖 360°，不能逐根手写互不相关的空间坐标。

至少验证收拢、半开和全开三态：每根主肋/撑杆长度不变、撑杆两端分别落在滑套
与主肋连接点、各方位末端半径相等、实体局部轴与解析方向一致，并检查首尾状态
可重复。若三角闭合无实数解，应修正几何参数，不能跳过该方位。

若某个角度无实数解，应修正几何参数（连杆长度必须大于曲柄半径），不能通过跳过该采样点掩盖问题。
