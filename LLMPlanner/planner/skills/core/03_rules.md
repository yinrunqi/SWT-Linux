## 通用建模原则

- 先从用户输入提取几何约束和尺寸，再选择最少且稳定的特征序列；不要按物体名称套固定答案。
- 标准实体流程：`new_part → select_plane → 闭合草图 → feature_*`。
- `feature_extrusion`、`feature_cut_extrusion`、`feature_revolve` 会自动退出草图。
- 同一特征事务中的选面、草图和拉伸/切除必须连续执行，避免留下半成品草图。
- 重复特征优先使用 `sketch_circles`、`feature_linear_pattern` 或
  `feature_circular_pattern`，不要手工枚举大量相同操作。

## 基准面、坐标与拉伸方向

| 基准面 | 草图轴 | 默认拉伸法向 |
|---|---|---|
| front / index=0 | 草图 x→模型 X，草图 y→模型 Y | +Z |
| top / index=1 | 草图 x→模型 X，草图 y→模型 -Z | +Y |
| right / index=2 | 草图 x→模型 -Z，草图 y→模型 Y | +X |

- `flipDirection=true` 仅在需要翻转默认方向时使用。
- `midPlane=true` 让拉伸轴范围为 `[-depth/2,+depth/2]`；否则范围通常为
  `[0,depth]`，中心在 `depth/2`。
- 选面射线使用模型 3D 坐标：起点在目标面外侧，方向指向实体内部。
- 不要固定假设 front 面最好。应按输入中的 `base_view` 和后续特征可达性选择基准面，
  并用上表推导实际拉伸轴。

## 实体面草图坐标

- 在基准面画草图时通常传 2D 坐标。
- 在实体面画草图时传模型 3D 坐标；服务端用 `ModelToSketchTransform` 转换。
- 平面法向沿哪个轴，该轴坐标就必须固定为面的实际位置；只改变另外两个面内轴：
  - X 法向面：固定 `cx`，改变 `cy/cz`
  - Y 法向面：固定 `cy`，改变 `cx/cz`
  - Z 法向面：固定 `cz`，改变 `cx/cy`
- 射线起点与草图特征坐标是两套独立参数，禁止把 `rx/ry/rz` 当成圆心或轮廓坐标。

## 安全选面

- 从当前 `boundingBox` 推导目标面位置和射线方向，不使用写死坐标。
- 射线在面内的位置应落在实体材料上；中央可能被孔或凹槽挖空。
- 对矩形面，可从包围盒内取 `(min + 0.25·size)` 或 `(min + 0.75·size)`
  作为候选点，并避开已知孔/槽区域。
- 若射线失败，应读取新包围盒和面信息后改变候选点，不要原样重试。

## 草图拓扑

- 一个草图中的多个闭合轮廓只能完全分离或完全嵌套。
- 禁止轮廓相交但不嵌套，也禁止用第二个重叠轮廓“覆盖修正”第一个。
- L/T/H/十字形等凹多边形应先从尺寸推导有序顶点，再用一次
  `sketch_polyline {points:[...],closed:true}`。
- 需要合并的相交实体应拆成多个草图/特征，通过实体重叠区域合并。
- 多个同高凸台或同深孔可在同一草图中批量画完，再执行一次特征操作。

## 加料、切除与顺序

- 凸台、腿、把手、凸缘使用 `feature_extrusion`。
- 孔、槽、凹坑、内腔使用 `feature_cut_extrusion`。
- 贯穿孔用 `endCondition="through_all"`；盲孔用 `blind` 并传深度。
- 面上切除默认沿面法向进入实体；不要因“向内切”而盲目设置 `flipDirection=true`。
- 若后续切除区域与某个加料特征的嵌入部分重叠，应先加料再切除，以清理内表面。
- 圆角/倒角通常最后执行，避免提前改变后续选面所依赖的拓扑。

## 容器与壁厚

没有 Shell 操作时，可用通用“外实体 + 顶面盲切”策略：

1. 从用户给定外尺寸创建实心主体。
2. 内轮廓尺寸按每个面内方向分别减去 `2·wallThickness`。
3. 切除深度为外高减底厚。
4. 验证外包围盒保持不变，且存在切除特征。

所有数值都必须从当前输入推导，不能使用固定容器尺寸。

## 拔模与旋转

- 相似截面的线性变化优先用拔模拉伸：
  `draftAngleDeg = degrees(atan((bottomHalf-topHalf)/depth))`；
  顶面更小用 `draftOutward=false`，更大用 `true`。
- 轴对称件优先旋转：中心线 + 位于中心线同一侧的闭合半截面 + `feature_revolve`。
- 阶梯轴、圆台等轮廓先按轴向位置排序，再生成不自交的折线。
- 不要用圆作为实心圆柱的旋转截面；否则会生成环面。

## 圆角、倒角与阵列

- 方盒语义边可使用 `top_front` 等两面交线名称。
- 圆柱、旋转体或局部圆边使用 `edgeSelection="ray"`。
- `edgeSelection="all"` 只在用户确实要求全部边时使用。
- 阵列前先创建一个有效种子特征；阵列的 count 包含种子本身。
- 线性阵列 spacing 是中心距；圆周阵列必须从输入推导轴、轴心、数量和角度。

## 输出前自检

- 所有尺寸已从 mm 换算为 m。
- 轮廓闭合、无自交、无重复覆盖。
- 每个操作的坐标与当前基准面/实体面一致。
- 所有用户明确要求的特征都有对应 operation。
- 不使用“其余同理”省略必要操作；能用一个批量高层操作时也不要展开为大量低层操作。
