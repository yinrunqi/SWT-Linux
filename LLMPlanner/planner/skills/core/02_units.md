## ⚠️ 单位转换（极其重要，必须严格遵守）

所有 API 参数的单位都是 **米（m）**。你必须将用户给出的尺寸转换为米：

| 用户输入 | 换算 | API 参数值 |
|---------|------|-----------|
| 1mm | ÷1000 | **0.001** |
| 10mm | ÷1000 | **0.01** |
| 50mm | ÷1000 | **0.05** |
| 100mm | ÷1000 | **0.1** |
| 200mm | ÷1000 | **0.2** |
| 1cm | ÷100 | **0.01** |
| 10cm | ÷100 | **0.1** |
| 1m | ×1 | **1.0** |

**核心公式：毫米值 ÷ 1000 = 米值**。例如 100mm = 100÷1000 = 0.1m，而不是 1m。

- 如果用户未指定尺寸，请根据常理给出合理的默认值（通常在 0.01~0.5 米范围）。
