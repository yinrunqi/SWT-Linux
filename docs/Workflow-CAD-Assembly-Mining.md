# 从 AutoMate 与 Fusion 360 挖掘通用装配 workflow：统计报告

本文回答一个问题：现有的装配 workflow（`assembly_ground_dof`、`assembly_gear_train`、`assembly_crank_slider`、`assembly_motion_check`）是针对两个试点手写的，能否用大规模真实装配数据找出覆盖一般装配体的 workflow。

使用两个数据集：AutoMate（Onshape，约 9.8 万个装配）做主统计，Fusion 360 Gallery Assembly（8,251 个装配）做交叉验证，并补充 AutoMate 缺少的顺序和接口信息。

结论先行：

- 数据足以支撑**接地、关节语义、拓扑生长、耦合关系、自由度预算**五类通用规则，覆盖面远超齿轮箱和发动机。两个数据集在接地、树深度、闭环类型上的结论方向一致。
- **装配顺序**：AutoMate 的配合列表不含顺序信息。Fusion 的时间线（`timeline_index`）含有顺序信息，并证实了两条规则：关节从地向外逐步添加，闭合回路的关节放在最后。
- **接口**：只看零件外形无法预测配合类型。Fusion 的关节引用几何给出了接口级规律，例如旋转副 35% 用两条圆边的圆心对接。完整的孔轴匹配规则仍需要 B-rep 几何。
- 真实用户经常不建运动：AutoMate 中齿轮状零件只有 41% 真的能动。“运动正确”是我们比数据集更严格的要求，不能指望从数据里学到。

## Onshape 配合与 SolidWorks 的对应

Onshape 的一个 mate 就是一个关节，SolidWorks 通常要 1 到 3 个标准配合组合出来。这张表是把挖掘结果落到我们系统上的前提：

| Onshape | 保留自由度 | SolidWorks 等价写法 | 我们现在是否支持 |
|---|---|---|---|
| FASTENED | 0 | 三个面重合；或同心 + 面重合 + 锁定旋转；或“锁定”配合 | 支持（组合） |
| REVOLUTE | 1 转 | 同心 + 端面重合 | 支持（`revolute_joint`） |
| SLIDER | 1 移 | 两对不平行平面重合；或同心轴 + 锁定旋转 | 支持（`slider_joint`） |
| CYLINDRICAL | 1 转 1 移 | 同心 | 支持 |
| PLANAR | 2 移 1 转 | 面重合 | 支持 |
| PARALLEL | 3 移 1 转 | 面平行 | 支持 |
| BALL | 3 转 | 球面同心，或点重合 | 部分（缺点重合） |
| PIN_SLOT | 1 转 1 移 | 槽口配合（`swMateSLOT`） | **缺** |
| 关系 GEAR | 耦合两条旋转 | 齿轮配合 | 支持 |
| 关系 RACK_AND_PINION | 耦合旋转与移动 | 齿条小齿轮配合 | **缺** |
| 关系 SCREW | 转移耦合 | 螺旋配合 | **缺** |
| 关系 LINEAR | 两条移动耦合 | 线性耦合配合 | **缺** |

## 主要统计

### 1. 配合类型（原始 129 万条）

固定 54.2%、平面 22.1%、旋转 9.8%、圆柱 7.2%、滑动 4.0%、平行 2.0%、球铰 0.5%、销槽 0.3%。

去重后的装配里，**66%** 至少有一个与地连通的可动关节，34% 是纯静态装配。

### 2. 零件外形无法预测配合类型

按包围盒把零件分成杆、盘、齿状盘、板、紧凑件、块六类后，各类零件对的配合分布几乎相同：固定约 50–58%，平面约 16–36%，旋转约 6–10%。唯一的例外是齿状盘与块的组合，旋转比例升到 14.6%。

结论：配合类型由**具体接口**决定（哪对面、孔轴是否匹配），外形类别不够。要挖接口级规则，需要读 B-rep，也就是 STEP 几何。

### 3. 接地

- 44.5% 的装配显式固定了零件，其余 55.5% 没有任何接地信息。JSON 里也没有配到原点的配合。
- 只固定一个零件时，它是**体积最大**零件的占 51.1%，是**配合最多**零件的占 42.2%。
- 被固定零件的外形：块 34.5%、板 22.4%，两者合计 57%。

规则：以最大的壳体、底座或板为地，并且显式固定。SolidWorks 默认会固定第一个插入的零件，所以插入顺序必须把地放在第一位。

### 4. 一对零件一个关节

- 91.3% 的零件对之间只有一条配合，6.1% 有两条，2.5% 有三条。
- 多条配合的组合里，最常见的是 平面+平面（23%）、圆柱+平面（21%，等价于旋转副）、三个平面（21%，等价于固定）、平面+滑动（9%，冗余）。

规则：先为每对零件选定关节语义，再展开成 SolidWorks 的配合组合，而不是逐条堆砌配合。平面+滑动这类冗余组合在 SolidWorks 里容易报过定义，应在展开时去掉。

### 5. 拓扑：以地为根的浅树

以地为根，按关节图做广度优先：

- 可动刚体到地的关节深度：1 层 43.5%、2 层 23.2%、3 层 13.5%，三层以内覆盖 80%。
- 直接连到地的第一个关节：旋转 29.4%、平面 17.6%、滑动 14.6%、圆柱 8.4%，三个平面组合 5.9%。
- 最常见的开链：旋转、平面、滑动、旋转>旋转、圆柱、旋转>旋转>旋转、滑动>旋转、旋转>滑动。

**闭环**：78.3% 的装配没有独立回路，8.2% 有 1 个，其余有多个。回路长度 3 占 44.7%、4 占 25.3%。回路签名多数是平面配合拼成的布局约束，而经典机构占比不高：

| 回路 | 占回路比例 | 典型机构 |
|---|---|---|
| 旋转×4 | 3.07% | 四连杆 |
| 圆柱+旋转×3 | 0.79% | 四连杆（一个铰用圆柱副） |
| 平行+旋转×2 | 0.71% | 平行连杆 |
| 旋转×3+滑动 | 0.70% | 曲柄滑块 |
| 旋转×6 | 0.54% | 六杆机构 |
| 圆柱+旋转×2+滑动 | 0.49% | 曲柄滑块（一个铰用圆柱副） |

规则：先搭从地出发的开链（生成树），**最后**再加闭合回路的那个关节，并单独检查闭环是否可装配。这和我们在曲柄滑块试点中遇到的问题一致：SolidWorks 的 Animation 解不了闭环。

### 6. 耦合关系

只有 4.6% 的装配用到 mateRelations，但它们的模式非常集中：

| 关系 | 占比 | 作用在 |
|---|---|---|
| 齿轮 GEAR | 64.1% | 两条旋转副（59.5%）；圆柱加旋转（2.4%）；两条圆柱副（1.9%） |
| 螺旋 SCREW | 19.4% | 一条圆柱副（19.0%） |
| 齿条小齿轮 RACK_AND_PINION | 10.8% | 旋转加滑动（10.0%） |
| 线性 LINEAR | 5.8% | 两条滑动副（4.9%） |

规则：耦合关系永远加在**已经存在的**运动副上。先分别建好两个旋转副，再加齿轮关系；先建圆柱副，再加螺旋关系。耦合关系本身不负责定位。

### 7. 自由度预算

用 Grübler 公式估算与地连通部分的活动度（每条配合按其约束数计，每条耦合关系扣 1，冗余不去除）：

- 活动度 1：21.2%（单自由度机构）
- 活动度 ≤ −3：20.9%（大量冗余约束）
- 活动度 ≥ 6：16.7%（有零件在浮动）
- 活动度 2 到 5：31.0%

真实数据里，欠约束和冗余都很常见。所以“活动度等于目标值”这个检查要由我们来强制执行，不能从数据里学到。

### 8. 用户常常不建运动

- 至少有一条配合的齿状盘零件里，只有 41.3% 与地之间存在可动关节，其余被固定或者浮动。这印证了 AutoMate 论文的观察：很多齿轮被标成 FASTENED。
- 顶层装配里 77.4% 没有子装配，14.1% 用了配合组（mate group）。

### 9. AutoMate 里挖不出装配顺序

按配合列表顺序，每条新配合是否接上“已放置集合”的比例是 0.8281；随机打乱后是 0.8277。两者没有差别，JSON 里的配合顺序不含建模顺序信息。

顺序信号改由 Fusion 360 的时间线提供，见下一节。

## Fusion 360 Gallery Assembly 交叉验证

| 项 | 内容 |
|---|---|
| 来源 | Fusion 360 Gallery Assembly Dataset a1.0.0（Autodesk） |
| 许可 | **仅限非商业研究**，不得整体再分发；本仓库只提交派生统计 |
| 使用部分 | 11 个 7z 包（18.8GB）逐包下载，只解出 `assembly.json`，几何不落盘，处理完即删除压缩包 |
| 规模 | 8,251 个装配；其中 1,684 个有关节（共约 1.9 万个），1,049 个有与地连通的运动 |
| 脚本 | `LLMPlanner/datasets/fusion360_assembly/{download,mine}.py`，统计在同目录 `stats.json` |

近似处理：关节一端为空（连到根组件）视为接地；嵌套组件若本身不参与任何关节，视为与父组件刚性连接；没有接地信息时，与 AutoMate 一样以体积最大的零件为地（424 个可动装配属于这种情况）。

### 同口径对比

| 指标 | AutoMate | Fusion 360 | 结论 |
|---|---|---|---|
| 固定类配合或关节占比 | 54.2% | 59.7% | 一致：多数连接是固定 |
| 旋转 / 滑动 / 圆柱 | 9.8% / 4.0% / 7.2% | 28.1% / 6.4% / 4.5% | Fusion 更偏机构 |
| 平面 | 22.1% | 0.75% | AutoMate 的平面配合多是 Onshape 特有的布局用法，不能当作通用规律 |
| 显式接地 | 44.5% | 42.0%（另有 12.7% 连到根组件） | 一致：约一半设计者不显式接地 |
| 单一接地件是体积最大的零件 | 51.1% | 56.6% | 一致 |
| 可动刚体在 3 层关节以内 | 80.2% | 90.9% | 一致：浅树 |
| 直接连到地的关节是旋转副 | 29.4% | 62.1% | 方向一致，Fusion 更集中 |
| 无闭环 | 78.3% | 91.1% | 一致：闭环是少数 |
| 回路中四连杆（旋转×4） | 3.1% | 21.0% | Fusion 回路里几乎没有布局噪声 |
| 回路中曲柄滑块（旋转×3+滑动） | 0.7% | 13.5% | 同上；加上一个铰换成圆柱副的变体（7.0%），曲柄滑块类约占五分之一 |
| 活动度为 1 | 21.2% | 33.0% | 单自由度机构是最常见的一类 |
| 活动度 ≥ 6（有零件浮动） | 16.7% | 20.8% | 一致：浮动很常见，需要我们强制检查 |
| 活动度 ≤ −3（大量冗余） | 20.9% | 3.7% | 冗余主要来自 Onshape 的平面配合叠加 |

### Fusion 独有的信号

**顺序**（973 个有 3 条以上带时间戳关节的装配）：

- 按时间线添加关节时，“接上已放置部分”的比例是 0.852；随机打乱是 0.762。设计者确实在从地往外生长。
- 闭合回路的那个关节平均排在全部关节的 68.7% 处，生成树上的关节平均在 48.8% 处（共 271 个闭合关节）。先建开链、最后闭环得到证实。
- 各类关节在时间线上的平均位置都在 0.46 到 0.54 之间，只有平面关节偏后（0.64）。也就是说，设计者并不是先把固定连接全部做完再做运动副，而是逐个零件地把它“放置并连接”好。
- 单一接地件在插入顺序中排第一的占 61.6%。

**接口**（关节两端引用的几何，“圆边@圆心”表示取圆形边的圆心）：

| 关节 | 最常见的引用 |
|---|---|
| 旋转 | 圆边@圆心 对 圆边@圆心 34.8%；圆边@圆心 对 平面@中心 8.3%；平面对平面 7.5%；圆弧对圆边 5.7% |
| 滑动 | 圆边对圆边 24.3%（轴在套里滑）；平面对平面 24.3%（导轨） |
| 圆柱 | 圆边对圆边 22.8%；柱面中段对柱面中段 7.8% |
| 球铰 | 球面@球心 对 球面@球心 59.5% |
| 固定 | 圆边@圆心 对 圆边@圆心 29.4%；平面对平面 17.2% |

在 SolidWorks 里，“两条圆边圆心对齐”等价于“柱面同心加端面重合”。所以旋转副的默认展开规则是：先找两侧的孔或轴圆柱面，做同心配合，再找端面做重合配合。

**运动限位**：31.1% 的滑动副启用了行程限制，旋转副只有 8.8%。所以滑动副默认应加限位（SolidWorks 的距离限制配合），旋转副通常不用。

**接触与孔**：接触面对中平面对平面占 57.1%，柱面对柱面占 20.6%。孔特征中通孔 78.8%、盲孔 15.1%、沉孔 2.1%、埋头孔 1.7%。

**领域**：有关节的装配中，77.6% 标注为 Product Design & Manufacturing；类别前几位是 Mechanical Engineering 40.0%、Product Design 10.0%、Machine design 5.5%、Tools 5.0%。

## 由统计导出的通用装配 workflow（已写成 v2 配方与工具）

| 步骤 | 规则 | 证据 | 对应配方或工具（v2） |
|---|---|---|---|
| G1 选地 | 最大的块或板件为地，第一个插入并显式固定 | 第 3 节；Fusion 中 56.6% 为最大件、61.6% 最先插入 | `assembly_topology`、`ground_component` |
| G2 按关节建模 | 每对零件先定关节语义，再按映射表展开成 SolidWorks 配合，去掉冗余；旋转副默认“柱面同心 + 端面重合”，滑动副默认加行程限位 | 第 4 节、映射表、Fusion 接口与限位统计 | `assembly_joint_mapping`、`joint`（fixed/revolute/slider/cylindrical/planar/ball/pin_slot，滑动副可带 `limit_min/limit_max`） |
| G3 从地生长 | 以地为根逐个零件“插入并连接”，不要先插完所有零件再统一加配合；三层以内覆盖 80–90% | 第 5 节；Fusion 时间线 0.852 对随机 0.762 | `assembly_topology` |
| G4 最后闭环 | 开链建完后再加闭合关节；闭环机构用运动学位姿加逐帧干涉检查验证 | 第 5 节回路表；Fusion 闭合关节排在 68.7% 处 | `assembly_linkage`、`close_loop`（先最小配合，过定义回滚） |
| G5 加耦合 | 在已有运动副上加齿轮、齿条、螺旋、线性关系 | 第 6 节 | `assembly_coupling`、`mesh_gears`、`rack_pinion`、`screw_pair`、`linear_coupler` |
| G6 预算自由度 | 每步之后用 Grübler 估算，要求与规格中的目标活动度一致；多出来的是浮动，少了的是冗余 | 第 7 节；两个数据集中都有约 20% 的装配有零件浮动 | `assembly_topology`、`check_dof` |
| G7 运动验证 | 驱动输入关节、采样、检查干涉和传动比 | 第 8 节（数据不提供，我们自己加） | `assembly_motion_check`、`check_motion` |

v1 与 v2 在减速箱、发动机两个试点上的对比见 [Workflow-CAD-Assembly.md](Workflow-CAD-Assembly.md) 第 5.3 节。

已补齐的工程量（2026-09-30）：

- C# 端新增配合类型：槽口（`swMateSLOT`）、齿条小齿轮（`swMateRACKPINION`）、螺旋（`swMateSCREW`）、线性耦合（`swMateLINEARCOUPLER`）、锁定（`swMateLOCK`），另加同心锁定旋转和距离限位。每种都在 SolidWorks 里实测过。
- 宏工具：`joint`（pin_slot、ball 等关节类型都在其中）、`rack_pinion`、`screw_pair`、`linear_coupler`、`close_loop`、`check_dof`。
- 配方：`assembly_topology`（覆盖 G1、G3、G6）、`assembly_joint_mapping`（G2）、`assembly_coupling`（G5）、`assembly_linkage`（G4 的四连杆和平行连杆）。

## 局限

- Onshape 用户群偏爱好者和教学项目，平面配合占比明显偏高，很多回路只是布局约束。工业装配的分布可能不同。
- 形状类别只依据包围盒，是粗粒度的启发式划分。
- 55% 的装配没有接地信息，其中 31,001 个可动装配的地是按“体积最大”推断的，第 5、7 节的数字受此影响。
- Grübler 估算不去除冗余，负值只说明约束有冗余，不能当作真实活动度。
- Fusion 数据只有 1,684 个装配有关节，回路总数 271 个。回路签名的比例在小样本上波动较大，只宜作为定性证据。
- Fusion 的时间线同时编号零件插入和特征操作，排名是在一个装配内部的相对位置，不同装配之间不可直接比较绝对值。
- Fusion 许可仅限非商业研究：原始数据不入库，论文里只报告聚合统计，并注明来源。
- 挖掘和配方编写只使用这两个数据集，不看减速箱、发动机两个试点的结果。配方冻结后才在试点上做前后对比。
